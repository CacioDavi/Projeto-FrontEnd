# Projeto-FrontEnd
Este é um projeto do programa Geração Tech, está sendo feito com base nos conteúdos vistos nas aulas de FrontEnd do programa.

# Orientações de Uso:
1. Faça um clone do projeto com `git clone <http>`
2. Abra a pasta do projeto no terminal
3. Execute `npm run dev` para iniciar o servidor da aplicação
4. Abra a página que o terminal mostrar
